# 🎙️ Mic Lab 3D — лаборатория расположения микрофонов

Приложение (PWA): работает в браузере, устанавливается на ПК и телефон, после первого открытия работает офлайн.

## Состав
- `index.html` — всё приложение
- `manifest.json` — название, иконки, цвета
- `sw.js` — офлайн-режим
- `icons/` — иконки
- `.nojekyll` — служебный файл для GitHub Pages

## Публикация на GitHub Pages (без командной строки)
1. Зайдите на github.com → **New repository**. Имя, например, `mic-lab`. Тип **Public**. Нажмите **Create repository**.
2. На странице репозитория нажмите **uploading an existing file**.
3. Распакуйте архив и **перетащите содержимое папки** (index.html, manifest.json, sw.js, папку icons и .nojekyll) в окно браузера.
   - Файлы должны лежать в корне репозитория, а не внутри вложенной папки.
   - Если `.nojekyll` не виден в проводнике, включите показ скрытых файлов. Без него всё равно будет работать.
4. Внизу нажмите **Commit changes**.
5. Откройте **Settings → Pages**. В разделе *Build and deployment* выберите **Source: Deploy from a branch**, ветка **main**, папка **/(root)**, нажмите **Save**.
6. Через 1–2 минуты вверху страницы появится адрес вида `https://ВАШ_ЛОГИН.github.io/mic-lab/`.

### То же через git (если удобнее)
```
git init
git add .
git commit -m "Mic Lab 3D"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/mic-lab.git
git push -u origin main
```
Затем шаги 5–6.

## Установка
**Компьютер (Chrome / Edge):** откройте адрес → в адресной строке значок «Установить» (или меню ⋮ → *Установить Mic Lab*).

**Android (Chrome):** откройте адрес → меню ⋮ → *Установить приложение* / *Добавить на главный экран*.

**iPhone / iPad (только Safari):** откройте адрес → кнопка «Поделиться» → *На экран «Домой»*.

## Обновление приложения
1. Замените `index.html` в репозитории (карандаш или **Add file → Upload files**, затем Commit).
2. В `sw.js` увеличьте номер: `miclab-v1` → `miclab-v2`.
3. Приложение у пользователей обновится при следующем открытии с интернетом (иногда нужно закрыть и открыть его два раза).

## Заметки
- Все расчёты идут на устройстве, сервера нет, данные никуда не отправляются.
- На телефоне 3D-сцена и сечения перехватывают касания: проведите пальцем по полям вокруг, чтобы прокрутить страницу.
- Для слабых телефонов уменьшите число микрофонов и частоту. Поиск источника по объёму самое тяжёлое место.
